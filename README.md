# 강의 스튜디오

책상에 앉아 **슬라이드 · 라이브 데모 · 영상**을 오가며 강의를 찍고, 편집 없이 MP4를 만드는 1인 강의 녹화 도구입니다.

- **큐시트**대로 리모컨(또는 키보드)의 `다음` · `다시`만 누르며 진행합니다.
- 녹화는 끊기지 않고 계속 돌아가며, 버튼은 "여기서 장면 바뀜 / 여기는 NG"만 기록합니다.
- **영상 만들기**를 누르면 NG를 빼고, 슬라이드 · 데모 화면 · 얼굴을 합쳐 MP4를 만듭니다.
- 슬라이드는 화면 녹화가 아니라 원본 PDF에서 가져오므로 선명하고, **촬영 후에 슬라이드를 고쳐도 다시 찍을 필요가 없습니다.**
- **대학 강의 영상 방식**: 발표자 뒤 배경을 AI로 지우고 슬라이드 옆에 세웁니다. 인사 장면에는 배경 이미지와 **이름 자막**(예: 황승환 교수 / 경북전문대학교 호텔외식학과)을 넣습니다. 초록 배경천 없이 책상에서 그냥 찍으면 됩니다.

맥북 + 크롬에서 쓰는 로컬 웹앱입니다. 녹화 파일은 모두 내 맥 안에만 저장됩니다.

> 그림으로 된 사용법은 앱 오른쪽 위의 **사용법**을 누르면 열립니다. 파일은 [`public/guide.html`](public/guide.html)입니다.

## 1. 처음 한 번만: 설치

1. **Node.js** 설치: <https://nodejs.org> 에서 **LTS** 버전을 받아 설치합니다.
2. **Google Chrome**이 있어야 합니다. 사파리에서는 안 됩니다.
3. 터미널에서 코드를 받고 설치합니다.

   ```bash
   git clone -b claude/intelligent-albattani-wazfgt https://github.com/linkedsugi/videoCreator.git
   cd videoCreator
   npm install
   ```

   `npm install`이 영상 변환에 쓰는 FFmpeg와 배경 지우기 AI도 함께 받습니다.

**새 버전으로 바꿀 때**: 강의 스튜디오 폴더에서 `git pull`을 실행합니다. 그다음 `강의스튜디오 실행.command`로 켜면 새로 필요한 파일을 알아서 설치합니다. 터미널로 켠다면 `npm install` 후 `npm start`를 실행하세요.

> **더 빠르게 (선택)**: Homebrew가 있다면 `brew install ffmpeg`를 한 번 실행하세요. 맥의 하드웨어 인코더를 써서 MP4 만들기가 몇 배 빨라집니다. 설치되어 있으면 자동으로 그쪽을 씁니다.

## 2. 실행

다음 둘 중 하나로 켭니다.

- Finder에서 **`강의스튜디오 실행.command`**를 더블클릭합니다.
  - 처음에 "확인되지 않은 개발자" 경고가 뜨면, 파일을 우클릭한 뒤 **열기**를 누르세요.
- 또는 터미널에서 `npm start`를 실행합니다.

켜지면 크롬에서 <http://localhost:4545> 가 자동으로 열립니다. 끌 때는 터미널 창을 닫으세요.

## 3. 사용 순서

### ① 큐시트 만들기
1. **새 강의 만들기**: 차시마다 하나씩 만듭니다. 예) "생성형 AI 입문 1차시"
2. **슬라이드 가져오기**: **PDF** 또는 **PowerPoint(.pptx, .ppt)** 파일을 고르거나 화면에 끌어다 놓습니다. 슬라이드마다 장면이 하나씩 생깁니다.
   - PowerPoint 파일을 올리면 슬라이드 제목은 장면 이름으로, **발표자 노트는 대본으로** 함께 들어옵니다.
   - PowerPoint 파일은 이 맥의 **PowerPoint**로 슬라이드 이미지를 만듭니다. PowerPoint가 없으면 Keynote, 그다음 LibreOffice를 씁니다.
   - 처음 한 번은 두 가지 허용 창이 뜰 수 있습니다.
     - "터미널이 Microsoft PowerPoint를 제어하려고 합니다" → **확인**
     - PowerPoint의 "파일 접근 권한" 창 → **접근 권한 부여**
   - 모양이 원본과 다르거나 변환이 안 되면, PowerPoint에서 PDF로 저장한 뒤 **PDF와 PowerPoint 파일을 함께** 고르세요. 이미지는 PDF에서, 노트는 PowerPoint 파일에서 가져옵니다.
   - 숨긴 슬라이드는 빠집니다. PowerPoint의 PDF 저장과 같은 규칙입니다.
3. **대본 넣기**: PowerPoint 파일로 가져왔다면 이미 들어가 있습니다. 그 밖의 방법은 다음과 같습니다.
   - **발표자 노트 → 대본**: PDF로 가져온 뒤, 같은 발표 파일(.pptx, .ppt)에서 대본만 채웁니다.
   - **대본 한꺼번에 붙여넣기**: 장면과 장면 사이를 `---` 한 줄로 구분해서 붙여넣습니다.
   - 장면마다 직접 입력합니다. 입력하면 자동으로 저장됩니다.
4. **데모 · 영상 · 얼굴 장면 끼워 넣기**: 장면 사이에 마우스를 올리면 **+ 여기에 장면 추가**가 나타납니다.

   | 장면 | 완성 영상 화면 | 촬영 중 할 일 |
   |---|---|---|
   | 슬라이드 | 슬라이드 + 발표자 | 대본 보고 설명 |
   | 데모 | 데모 탭 화면 + 발표자(작게) | 데모 탭에서 라이브 시연 |
   | 영상 | 데모 탭 화면 (발표자 없음) | 데모 탭에서 유튜브 등 재생 |
   | 얼굴 | 발표자 크게 + 이름 자막 | 카메라 보고 말하기 (인사·마무리) |

   장면마다 **발표자**를 켜고 끌 수 있습니다. 퀴즈 화면처럼 슬라이드만 보여야 하는 장면은 끄세요.

> 슬라이드를 고친 뒤 파일을 다시 가져오면 **이미지와 제목만 바뀌고** 촬영본은 그대로입니다. 대본을 발표자 노트로 덮어쓸지는 물어봅니다.
> 영상을 다시 만들면 고친 슬라이드가 들어갑니다.

### ② 화면 구성 (처음 한 번)
강의 화면 위쪽의 **화면 구성**에서 완성 영상의 모양을 정합니다. 왼쪽에 크게 보이는 미리보기 그대로 영상이 만들어집니다.

- **화면 방식**: **발표자 합성**(배경을 지우고 슬라이드 위에, 대학 샘플 방식) 또는 **작은 얼굴 창**(카메라 화면을 모서리에 작게).
- **발표자 위치**: 자동 · 수동 · 반자동 모두 됩니다.
  - **자동**: 슬라이드마다 내용이 적은 쪽(오른쪽/왼쪽)에 섭니다. 양쪽 다 차 있으면 슬라이드를 줄여 옆에 섭니다.
  - **수동**: **오른쪽** 또는 **왼쪽**으로 고정합니다.
  - **반자동**: 자동으로 두고, 아래 **장면별 미리보기**에서 마음에 안 드는 장면만 골라 **오른쪽 · 왼쪽 · 줄이기 · 발표자 없음**으로 바꿉니다.
  - 미리보기에서 발표자를 **좌우로 끌어** 위치를 옮기고, **크기** 막대로 크기를 정합니다.
- **배경 지우기**: **AI 자동**(그냥 책상에서 찍기) 또는 **초록 배경천**(크로마키). AI는 이 맥에서 돌아가고 인터넷이나 비용이 들지 않습니다.
- **얼굴 장면 배경**: 인사·마무리 장면에서 발표자 뒤를 **원래 배경 · 흐리게 · 이미지** 중에서 고릅니다. 이미지는 사진 파일이나 **슬라이드에서 고르기**(예: 강의 표지 슬라이드)로 넣습니다.
- **이름 자막**: 이름과 소속을 넣으면 얼굴 장면이 시작될 때 약 8초 동안 왼쪽 아래에 나옵니다. 색과 표시할 장면(첫 얼굴 장면 / 모든 얼굴 장면)을 고릅니다.

미리보기의 발표자는 **촬영 화면에서 카메라를 켤 때 찍힌 사진**(녹화 뒤에는 최근 녹화)으로 만듭니다. 처음에는 회색 인물로 자리만 보여 줍니다.

> 새 강의를 만들면 **가장 최근 강의의 화면 구성**(자막, 배경 이미지, 위치)을 그대로 이어받습니다. 10차시를 찍어도 한 번만 정하면 됩니다.

### ③ 촬영
1. **● 촬영하기**를 누르고 카메라와 마이크를 고릅니다.
   - 아이폰도 카메라로 쓸 수 있습니다. 아래 **아이폰 카메라로 찍기**를 보세요.
2. **데모 탭 연결** (데모 · 영상 장면이 있을 때)
   - 데모에 쓸 크롬 탭(ChatGPT 등)을 고르고, **"탭 오디오도 공유"를 켭니다.** 그래야 유튜브 소리가 녹음됩니다.
   - 그 탭의 화면과 소리만 녹화됩니다. 알림, 북마크바, 다른 창은 찍히지 않습니다.
   - 데모용 탭은 **새 창**으로 따로 띄워 두면 편합니다.
3. **프롬프터 창 띄우기**: 대본이 뜨는 작은 창입니다.
   - **카메라 바로 아래**로 옮겨 두면 대본을 읽어도 카메라를 보는 것처럼 보입니다.
   - 데모 중에도 맨 위에 떠 있고, 녹화에는 찍히지 않습니다.
4. **● 녹화 시작** → 3초 카운트다운 후 진행합니다.

| 동작 | 리모컨 | 키보드 | 의미 |
|---|---|---|---|
| 다음 | ▶ (PgDn) | → / 스페이스 | 지금 장면 OK, 다음 장면으로 |
| 다시 | ◀ (PgUp) | ← | 지금 장면 NG, 처음부터 다시 (3초 카운트다운) |
| 일시정지 / 이어서 | - | B | 잠깐 멈췄다가 같은 장면을 이어서 |
| 이전 장면 | - | 화면 버튼 | 앞 장면을 다시 찍기 |

- **데모 중에는** 리모컨 신호가 데모 탭으로 가므로, 프롬프터 창의 **[다음]** 버튼을 마우스로 누르세요.
- 오른쪽 장면 목록을 클릭하면 그 장면으로 바로 가서 찍습니다.
- 같은 장면을 여러 번 찍으면 **가장 최근의 NG가 아닌 테이크**를 씁니다.
- 끝나면 **■ 녹화 종료**를 누릅니다.
- 빠진 장면은 **이어서 촬영**으로 나중에 찍어도 됩니다. 여러 날에 나눠 찍어도 됩니다.
- 녹화는 1초마다 디스크에 저장됩니다. 브라우저가 꺼져도 그 직전까지는 남고, 찍던 장면도 영상 만들기에서 살려 씁니다.

### ④ 영상 만들기
**테이크 · 영상 만들기** 화면에서 다음을 할 수 있습니다.
- 지금 화면 구성을 확인합니다. 바꾸려면 **화면 구성 바꾸기**를 누릅니다.
- 장면별 테이크를 봅니다. 마음에 안 드는 테이크를 **[제외]**하면 그 전 테이크가 쓰입니다.
- **MP4 만들기**를 누릅니다. 완성 파일은 `projects/<강의 폴더>/exports/`에 저장되고, **Finder에서 보기**로 바로 열 수 있습니다.
  - 결과물: 1920×1080, 30fps, H.264/AAC MP4
  - 소리 크기 자동 맞춤이 켜져 있으면 차시마다 볼륨이 같게 맞춰집니다.

**35분 강의**(촬영 원본 약 45분)는 처음 만들 때 맥북에서 대략 **15~30분** 걸립니다. Homebrew FFmpeg가 있으면 더 빠릅니다.
- **발표자 합성**은 발표자 배경을 지우는 단계가 더해져, 처음 만들 때 35분 강의 기준 **5~15분쯤 더** 걸립니다(맥 사양에 따라 다름). 지운 결과는 저장해 두므로 다시 만들 때는 빠릅니다.
- 그동안 맥이 잠들지 않게 막아 둡니다. **터미널 창만 닫지 마세요.** 브라우저 탭은 닫아도 계속 만듭니다.
- 다시 만들 때는 바뀐 장면만 새로 만들어서 몇 분이면 됩니다.
- 35분짜리를 끝까지 만들어 시험해 봤습니다. 길이는 정확히 맞았고, 끝부분까지 소리와 화면이 어긋나지 않았습니다.

## 아이폰 카메라로 찍기 (연속성 카메라)

아이폰을 맥 가까이에 **가로로 거치하고 화면을 잠그면**, 카메라 목록에 "○○의 iPhone 카메라"가 나타납니다.

조건:
- 맥과 아이폰이 같은 Apple ID로 로그인되어 있어야 합니다.
- Wi-Fi와 블루투스가 켜져 있어야 합니다.
- macOS 13 이상, iOS 16 이상이어야 합니다.

맥 메뉴 막대의 **제어 센터 → 비디오 효과**에서 인물 모드나 스튜디오 조명도 켤 수 있습니다.

## 촬영 팁

- **배경 지우기(AI)를 깔끔하게**: 상반신이 화면에 나오게 앉고, 뒤쪽은 단순하고 밝을수록 좋습니다. 얼굴에 빛이 고르게 오게 하세요. 의자 등받이나 뒤를 지나가는 사람도 함께 남을 수 있습니다.
- **초록 배경천**을 쓰면 가장 깔끔합니다. 천에 주름이 덜 지게 펴고, 초록색 옷은 피하세요.
- **이어폰**을 쓰세요. 스피커로 나온 영상 소리가 마이크에 다시 들어가지 않습니다. 완성 영상에는 탭 소리가 따로 깨끗하게 들어갑니다.
- **방해금지 모드**를 켜 두세요.
- 맥북 내장 마이크는 키보드 바로 옆이라 타이핑 소리가 크게 들어갑니다. 라이브 데모가 많다면 **핀마이크 등 외장 마이크**를 권합니다.
- 녹화 원본은 차시당 수 GB입니다. 저장 공간을 넉넉히 두세요.
- 공개 강의라면 다른 사람의 유튜브 영상을 넣기 전에 저작권을 확인하세요. 저작권법 25조(수업 목적 이용)는 학교 LMS에서 수강생에게만 제공할 때 적용됩니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 카메라가 안 보임 | 크롬 주소창 왼쪽 아이콘 → 카메라·마이크 허용.<br>시스템 설정 → 개인정보 보호 및 보안 → 카메라 / 마이크 → Google Chrome 켜기 |
| 데모 탭 소리가 안 녹음됨 | 데모 탭 연결 때 "탭 오디오도 공유"를 켜야 합니다. 연결을 끊고 다시 연결하세요. |
| 탭이 아니라 창·전체 화면을 공유하고 싶음 | 시스템 설정 → 개인정보 보호 및 보안 → **화면 및 시스템 오디오 녹음** → Google Chrome 켜기. 이 경우 프롬프터 창도 함께 찍힐 수 있으니 탭 공유를 권합니다. |
| PowerPoint 파일 변환이 안 됨 | 시스템 설정 → 개인정보 보호 및 보안 → **자동화** → 터미널 → Microsoft PowerPoint(또는 Keynote)를 켜세요. 그래도 안 되면 PDF와 PowerPoint 파일을 함께 고르세요. |
| "포트 4545를 이미 쓰고 있습니다" | 이미 켜져 있습니다. 크롬에서 <http://localhost:4545> 를 여세요. |
| MP4 만들기가 느림 | `brew install ffmpeg` 후 서버를 다시 켜면 하드웨어 인코더를 씁니다. |
| "FFmpeg를 찾지 못했습니다" | `npm install`을 다시 실행하거나 `brew install ffmpeg`로 설치하세요. |

## 데이터

모든 데이터는 `projects/` 폴더에 있습니다. 강의 폴더를 통째로 복사하면 백업됩니다.

**저장 공간**: 35분 강의 하나에 대략 아래만큼 씁니다. 영상 만들기 화면 아래쪽에서 이 강의가 쓰는 공간과 맥의 남은 공간을 볼 수 있습니다.

| 파일 | 크기 |
|---|---|
| 녹화 원본 | 약 3GB |
| 중간 파일 | 약 5GB |
| 완성 영상 | 약 1GB |

- 영상을 만들 때는 맥에 **20GB 이상** 비워 두세요.
- 영상을 다 만든 강의는 **[정리]**로 중간 파일을 지우세요. 녹화 원본과 완성 영상은 남습니다.

```
projects/<강의>/project.json        큐시트·설정
projects/<강의>/slides/             슬라이드 이미지
projects/<강의>/assets/             화면 구성: 얼굴 장면 배경, 이름 자막, 미리보기용 카메라 사진
projects/<강의>/sessions/<촬영>/    녹화 원본(camera.webm, screen-N.webm)과 기록(events.jsonl)
projects/<강의>/build/              영상 만들기용 중간 파일 (지워도 다시 생김)
projects/<강의>/exports/            완성 MP4
```

## 개발

```bash
npm test      # 타임라인 계산, 화면 구성 계산, 배경 지우기, 합성 영상으로 MP4 만들기, PowerPoint 변환(LibreOffice가 있을 때) 테스트
npm run dev   # 서버 코드를 고치면 자동 재시작
```

구조:
- `server/`
  - `store.js`: 파일 저장
  - `convert.js`: PowerPoint 파일 → PDF·PPTX 변환
  - `build/timeline.js`: 녹화 기록 → 테이크 → 장면 구간
  - `build/scene.js`: 슬라이드의 빈 쪽 찾기, 카메라 속 발표자 위치 찾기
  - `build/builder.js`: FFmpeg 합성
  - `matting/`: 발표자 배경 지우기 (워커 스레드, ONNX Runtime WebAssembly).
    모델은 MediaPipe Selfie Segmenter(Apache 2.0)를 ONNX로 바꾼 것입니다. `matting/models/NOTICE.md` 참고.
  - `look.js`: 화면 구성 미리보기용 발표자 사진
- `public/js/`
  - `look.js`: 장면 구도 계산 (서버의 영상 만들기와 브라우저 미리보기가 같이 씀)
  - `views/`: 화면
  - `studio/`: 녹화·프롬프터
  - `importers/`: PDF 렌더링, PPTX 제목·노트 읽기
